# ルビカメラ（RubyCam）

外国語で書かれた紙をカメラで撮ると、**その言語の読み方をふりがな（ルビ）で返す**Webアプリです。

写真の上にルビを重ねる表示と、読み取った文章にルビを振る表示の2つを持ちます。
語をタップするとその単語だけを読み上げます。

## 対応言語

| 言語 | ルビ | 読みの出しかた |
|---|---|---|
| 英語 | カタカナ | 頻出語辞書（約520語）＋綴りからの推定 |
| 中国語 | ピンイン / カタカナ | pinyin-pro で漢字→ピンイン、ピンイン→カタカナは自前 |
| 韓国語 | カタカナ / ローマ字 | ハングルを字母に分解し、連音化・鼻音化・濃音化などを適用 |
| ベトナム語 | カタカナ＋声調 | 音節を頭子音+韻に分解。北部/南部を切替。綴りの誤りを自動補正 |
| スペイン語 | カタカナ | 綴り規則 |
| フランス語 | カタカナ | 綴り規則（鼻母音・語末の黙字を明示的に処理） |
| ドイツ語 | カタカナ | 綴り規則（母音の長短・語末無声化・ch の分岐） |
| イタリア語 | カタカナ | 綴り規則 |
| ポルトガル語 | カタカナ | 綴り規則 |
| ロシア語 | カタカナ / ローマ字 | キリル文字の転写 |
| ギリシャ語 | カタカナ / ローマ字 | ギリシャ文字の転写 |

ラテン文字の言語は、読み取った文章から言語を推定して切り替えを提案します。
ハングル・漢字・キリル・ギリシャ文字は文字種で判別できます。

## 手に入れる

### スマートフォンで使う（推奨: URLで開く）

**`https://<ユーザー名>.github.io/<リポジトリ名>/`**

ブラウザのメニューから **「ホーム画面に追加」** すると、
アプリのアイコンが並び、次からは1タップで開けます。

この形をすすめるのは、**ブラウザが https 以外ではカメラを渡さないため**です。
URLで開いた場合だけ、画面内にカメラ映像を出してその場で撮る操作ができます。

> 初回だけリポジトリ側の設定が要ります。
> **Settings → Pages → Source を「GitHub Actions」** に変えると、
> `.github/workflows/pages.yml` が動いて公開されます。

### ファイルを保存して使う

**`dist/rubycam.html` を保存すれば、それだけで動きます。**
アプリ全体（HTML・CSS・11言語ぶんの読み生成）を1ファイル（約75KB）にまとめてあるので、
インストールも配信サーバも要りません。ダブルクリックで開いてください。

スマートフォンに保存して開いた場合、**画面内カメラは使えませんが、
「カメラで撮る」から端末の標準カメラを呼び出せます。** 使い勝手は変わりません。
ホーム画面への追加はできないため、日常的に使うならURL版のほうが向きます。

## 動かす

```bash
npm start          # http://localhost:8080 で配信（完全版）
npm test           # 読みの生成を検証（22 テスト）
npm run build      # dist/rubycam.html（1ファイル版）を作り直す
npm run package    # dist/rubycam.zip（配布一式）を作る
```

カメラを使うには **https か localhost** である必要があります（ブラウザの制約）。
`file://` で開いた1ファイル版では、環境によってカメラが起動できないことがありますが、
**「写真を選ぶ」（スマホなら撮影も選べます）はどこでも動きます。**

## 仕組み

```
写真 ─→ 局所しきい値で白黒に整える（影・光のむらを消す）
          │
          ├─→ Tesseract.js（文字認識・単語ごとの座標つき）
          │
          ├─→ 言語判定（文字種 + 綴りの癖 + 機能語）
          │
          ├─→ 綴りの補正（ベトナム語のみ）
          │
          └─→ 読みの生成
                綴り ──[言語ごとの規則]──→ 音素表記 ──[共通表]──→ カタカナ
```

### 写真を整える

紙をカメラで撮ると、影や光のむらで濃さが場所ごとに変わります。
画像全体で1つのしきい値を決めると、影の側の文字が潰れるか、
明るい側の地色が黒く残ります。そこで**その画素の周りの平均と比べる
局所しきい値**にしています（`src/enhance.js`）。
積分画像を使うので、窓の大きさに関係なく1画素あたり一定の計算量です。

白抜き文字の看板などで白黒が反転した場合は、暗い画素が過半かどうかで
判定して戻します。設定の「文字を読みやすく補正する」で切れます。

### ベトナム語

ベトナム語の音節は「頭子音 + 韻」に必ず分かれ、**取りうる韻は限られています**。
そこで韻の一覧表（`src/lang/vi.js` の `RHYMES`、約160種）を1つ持ち、
2つの用途に使っています。

1. **読みの生成** — 韻から音素へ引く。`anh`→アイン、`ach`→アック のような
   母音のずれや、`ơ`/`ư` が長母音であること（`phở`→フォー）を表に持たせている
2. **綴りの検査と補正** — 表に無い綴りは、ベトナム語として成り立たない音節。
   文字認識が記号を落としたと見て、記号を付け替えて直せるか試す

補正は**直し方が一意に決まるときだけ**行います。候補が複数あるときや、
記号が1つも読めていない語（元からそうなのか読み落としか区別できない）は
そのままにします。直した語は点線の下線で示し、元の綴りも見られます。

発音は**北部（ハノイ）が既定**で、南部（ホーチミン）も選べます。
`d` `gi` `r` `s` `v` は南北で最も大きく違うため、ここを切り替えています
（例: `dài` は北部でザイ、南部でヤイ）。声調はルビの末尾に記号で添え、
凡例を画面に出します。

読みの生成は**音素表記を挟む2段構え**にしています。
カタカナの当て方を `src/kana.js` の1箇所に集約することで、
言語をまたいで表記が揺れないようにするためです。

```
src/
  kana.js          音素 → カタカナ（全言語で共通）
  ocr.js           Tesseract.js の読み込みと単語・行の取り出し
  app.js           撮影・表示・読み上げ
  lang/
    rules.js       綴り → 音素 のルールエンジン
    index.js       言語一覧・言語判定・ルビを振る単位への切り分け
    en.js / en-dict.js / zh.js / ko.js / vi.js / ru.js / el.js / de.js / fr.js / romance.js
```

## 通信するもの／しないもの

- **写真は端末から出ません。** 文字認識も読みの生成もブラウザ内で完結します。
- 初回だけ、文字認識エンジン（Tesseract.js）と言語データ、
  中国語のピンイン辞書（pinyin-pro）をCDNから取得します。以降はブラウザに残ります。
- CDNは jsDelivr → unpkg の順に試します。

## 精度について

読みは**発音の目安**です。特に次は原理的に外れます。

- **英語の未知語** — 綴りから推定します。UIでは薄い色のルビで区別しています。
- **強勢（アクセント）の位置** — スペイン語・イタリア語などの長音は再現しきれていません。
- **中国語の声調** — ピンイン表示なら記号で分かりますが、カタカナには乗りません。
- **文字認識そのもの** — 手書き、傾き、暗い写真では読み違えます。
