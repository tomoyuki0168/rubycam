# ルビカメラ（RubyCam）

外国語で書かれた紙をカメラで撮ると、**その言語の読み方をふりがな（ルビ）で返す**Webアプリです。

写真の上にルビを重ねる表示と、読み取った文章にルビを振る表示の2つを持ちます。
語をタップするとその単語だけを読み上げます。

## 対応言語

| 言語 | ルビ | 読みの出しかた |
|---|---|---|
| 英語 | カタカナ | 頻出語辞書（約520語）＋綴りからの推定 |
| 中国語 | ピンイン / カタカナ | pinyin-pro で漢字→ピンイン、ピンイン→カタカナは自前 |
| 韓国語 | カタカナ / ローマ字 | ハングルを字母に分解し、連音化・鼻音化・濃音化などを適用 |
| ベトナム語 | カタカナ | 声調記号を外して音節を解析（声調は別に保持） |
| スペイン語 | カタカナ | 綴り規則 |
| フランス語 | カタカナ | 綴り規則（鼻母音・語末の黙字を明示的に処理） |
| ドイツ語 | カタカナ | 綴り規則（母音の長短・語末無声化・ch の分岐） |
| イタリア語 | カタカナ | 綴り規則 |
| ポルトガル語 | カタカナ | 綴り規則 |
| ロシア語 | カタカナ / ローマ字 | キリル文字の転写 |
| ギリシャ語 | カタカナ / ローマ字 | ギリシャ文字の転写 |

ラテン文字の言語は、読み取った文章から言語を推定して切り替えを提案します。
ハングル・漢字・キリル・ギリシャ文字は文字種で判別できます。

## 動かす

```bash
npm start          # http://localhost:8080 で配信
npm test           # 読みの生成を検証（17 テスト）
```

カメラを使うには **https か localhost** である必要があります（ブラウザの制約）。
撮影済みの写真を選ぶ経路は http でも動きます。

## 仕組み

```
写真 ─→ Tesseract.js（文字認識・単語ごとの座標つき）
          │
          ├─→ 言語判定（文字種 + 綴りの癖 + 機能語）
          │
          └─→ 読みの生成
                綴り ──[言語ごとの規則]──→ 音素表記 ──[共通表]──→ カタカナ
```

読みの生成は**音素表記を挟む2段構え**にしています。
カタカナの当て方を `src/kana.js` の1箇所に集約することで、
言語をまたいで表記が揺れないようにするためです。

```
src/
  kana.js          音素 → カタカナ（全言語で共通）
  ocr.js           Tesseract.js の読み込みと単語・行の取り出し
  app.js           撮影・表示・読み上げ
  lang/
    rules.js       綴り → 音素 のルールエンジン
    index.js       言語一覧・言語判定・ルビを振る単位への切り分け
    en.js / en-dict.js / zh.js / ko.js / vi.js / ru.js / el.js / de.js / fr.js / romance.js
```

## 通信するもの／しないもの

- **写真は端末から出ません。** 文字認識も読みの生成もブラウザ内で完結します。
- 初回だけ、文字認識エンジン（Tesseract.js）と言語データ、
  中国語のピンイン辞書（pinyin-pro）をCDNから取得します。以降はブラウザに残ります。
- CDNは jsDelivr → unpkg の順に試します。

## 精度について

読みは**発音の目安**です。特に次は原理的に外れます。

- **英語の未知語** — 綴りから推定します。UIでは薄い色のルビで区別しています。
- **強勢（アクセント）の位置** — スペイン語・イタリア語などの長音は再現しきれていません。
- **中国語の声調** — ピンイン表示なら記号で分かりますが、カタカナには乗りません。
- **ベトナム語の声調** — カタカナには乗りません（内部では保持しています）。
- **文字認識そのもの** — 手書き、傾き、暗い写真では読み違えます。
